# Mobile UI notes

- Landscape; stretch mode `canvas_items`, aspect `expand`; respect safe areas.
- HUD: HP/resource bars, turn indicator, status icons, 4–6 skill buttons, collapsible log, pause/speed/auto/settings.
- Touch targets ≥ 48dp; long-press for tooltips; boss telegraphs prominent.
- Glanceable: who acts, what is coming, how dangerous.
