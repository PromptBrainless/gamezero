# ECHO//BRUCH (gamezero)

Privates Spielprojekt: taktisches 1v1-Duell im Browser (siehe `src/`) sowie
die Planung eines Godot-basierten, mobile-first 2D-Seitenansicht-Kampf-RPGs.

- Entwicklung: `npm install && npm run dev` (Port 8080)
- Design- und Planungsdokumente: [`docs/`](docs/README.md)
  - Einstieg: [Mini-GDD](docs/mini-gdd.md)
