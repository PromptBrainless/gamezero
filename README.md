# ECHO//BRUCH

Mobile-first 2D side-view turn-based 1v1 combat game.

**Direction: Godot.** The new project lives in [`godot/`](godot) (open that folder in Godot 4.4+). Plans are in [`docs/`](docs/README.md). The original web prototype (Vite/React in `src/`) is kept as a rules reference.

## Next steps
1. Implement `TurnResolver` and tests against the w100 rules.
2. Build the combat scene and HUD with placeholder art.
3. Add data resources for the vertical slice (see `docs/godot-project-plan.md`).

## Web prototype
`npm install && npm run dev`
